  The number on the flat layout is HALF THE FOLD ANGLE:
  90 = square edge, 45 = ordinary square building corner.

      saw tilt = 90 - shown        (0 on your scale = blade square to the face)

  so shown 65 -> set 25,  shown 45 -> set 45,  shown 135 -> flip and set 45.
  tilt over 45 -> 45 deg JIG, set (tilt - 45).
